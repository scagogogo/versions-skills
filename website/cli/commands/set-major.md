# versions set-major

::: info 命令
```bash
versions set-major <version-string> <major>
```
:::

## 📖 简介

修改版本号的 Major 号（不可变修改，返回新版本）

修改版本号的 Major 版本号，返回新版本字符串。原版本不变。

示例:
  versions set-major 1.2.3 2  # 2.2.3

# versions set-patch

::: info 命令
```bash
versions set-patch <version-string> <patch>
```
:::

## 📖 简介

修改版本号的 Patch 号（不可变修改，返回新版本）

修改版本号的 Patch 版本号，返回新版本字符串。原版本不变。

示例:
  versions set-patch 1.2.3 9  # 1.2.9

# versions info

::: info 命令
```bash
versions info <version-string>
```
:::

## 📖 简介

显示版本号的完整信息

显示版本号的所有详细信息，包括结构化组成部分和所有类型判断（Is* 方法）。

示例:
  versions info v1.2.3-beta1
  versions info 2.0.0

# versions set-minor

::: info 命令
```bash
versions set-minor <version-string> <minor>
```
:::

## 📖 简介

修改版本号的 Minor 号（不可变修改，返回新版本）

修改版本号的 Minor 版本号，返回新版本字符串。原版本不变。

示例:
  versions set-minor 1.2.3 5  # 1.5.3

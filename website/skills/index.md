# Skills 斜杠命令

versions-skills 提供 **14 个 Claude Code Skills**（斜杠命令），每个对应一类版本操作。Skills 同时覆盖 SDK / CLI / MCP 三层入口。

::: tip 安装
首次使用需先运行 [`/installation`](/skills/installation) 完成 SDK / CLI / MCP 一次性配置。
:::

# EmptyVersionPrefix

::: info const
```go
const EmptyVersionPrefix VersionPrefix = ""
```
:::

## 📖 说明

EmptyVersionPrefix 表示一个空的前缀

该常量用于表示版本号没有前缀的情况，如纯数字版本号 "1.2.3"。
它也用于检查版本前缀是否为空。

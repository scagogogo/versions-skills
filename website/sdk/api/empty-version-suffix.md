# EmptyVersionSuffix

::: info const
```go
const EmptyVersionSuffix VersionSuffix = ""
```
:::

## 📖 说明

EmptyVersionSuffix 空的后缀

该常量用于表示版本号没有后缀的情况，如纯数字版本号 "1.2.3"。
它也用于检查版本后缀是否为空。

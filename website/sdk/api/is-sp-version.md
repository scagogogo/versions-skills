# IsSP

::: info 方法 · `Version`
```go
func (x *Version) IsSP() bool
```
:::

## 📖 说明

IsSP 判断版本是否为服务包版本

服务包版本是指后缀包含 sp 标识的版本，如 "1.0.0-sp1"。
